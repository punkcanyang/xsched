# X 预排推文工具：现成方案调查（2026-10-09）

> 方向（老闆已拍板）：**不用 X 官方 API**。做一个改页面的 Chrome 扩充，强化 x.com 自己的发文框：自动排时间、快速选时段、浏览目前的预排队列，底层仍用 X 原生的「排程」功能。
> 资料查于 2026-10-09（Asia/Shanghai）。CWS = Chrome Web Store，使用者数、评分、更新日期都是当天直接从商店页面抓到的。标「未验证」的是只有第二手来源，或我没能亲自确认。

## 4. 结论：还有什么空缺
- **已经有人做的**：「固定时段 + 一键填进原生排程」（AutoSkedule、Xchedule）、「快捷时间」（Shortcut、Schedule Helper）、「批量排」（XScheduler）。
- **都很小众**：使用者都在 210 人以下，评分少或没有，几个已经一两年没更新；Xchedule 还要用加密货币付款。
- **明显空缺**：没找到任何「不走 API」的扩充把 X 原生的 Scheduled 队列读出来，做成**日历或周视图**，标出哪些时段已经排了、哪里还空着，再让「下一个空时段」自动避开已排的时间。现有的时段工具只在本机记一个日期计数器，不会读 X 上真正的排程。
- 也没看到哪一个把「自动排、快速选时段、队列浏览」三件事做在一起。
- 我们自己做的风险：会依赖 x.com 的 DOM（X 改版就可能坏，跟 Chatseek 遇到的问题一样）；读取 Scheduled 列表要从 DOM 抓，或者读页面自己发出的请求结果，这一点要做技术验证（**未验证**是否可行）。
